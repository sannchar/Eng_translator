# 🌐 AutoTranslator

**AutoTranslator** — это удобная утилита для Windows, которая позволяет перевести любую напечатанную строку на английский язык по нажатию одной комбинации клавиш. Приложение работает в фоне (в системном трее) и не отвлекает вас от работы.

Идеально подходит для переписок с иностранными коллегами, написания кода или быстрого перевода мыслей.

---

## ✨ Особенности
- **Никаких окон** — работает незаметно в системном трее (возле часов).
- **Моментальный перевод** — использует `MyMemoryTranslator` (бесплатно, быстро, без ключей API).
- **Универсальность** — переводит текст прямо в том окне, где вы печатаете (браузер, мессенджер, IDE, Word).
- **Умная работа с раскладкой** — использует системные шорткаты `Ctrl+Insert` и `Shift+Insert` для обхода багов с русской раскладкой в Windows.

---

## 🚀 Как использовать

1. Откройте любой редактор, мессенджер или текстовое поле.
2. Напечатайте текст на русском языке.
3. Не снимая выделения или не убирая курсор с конца строки, нажмите **`Ctrl + Alt + T`**.
4. Программа автоматически выделит строку, переведет её и вставит английский вариант на место оригинала.

---

## 💾 Установка (Готовый .exe)

Вам не нужно устанавливать Python, чтобы пользоваться программой!

1. Скачайте `AutoTranslator.exe` из раздела **Releases** (или найдите в папке `dist` после локальной сборки).
2. Запустите файл. В трее (возле часов) появится иконка с синей буквой **T**.
3. Программа готова к работе!

---

## 🔄 Автозагрузка Windows

**Программа сама добавляет себя в автозагрузку при первом запуске!** Вам не нужно ничего делать вручную, просто запустите `.exe` файл один раз, и он всегда будет с вами.

**Как убрать из автозагрузки:**
Если вы захотите, чтобы программа не запускалась вместе с Windows:
1. Нажмите комбинацию клавиш `Ctrl + Shift + Esc`, чтобы открыть **Диспетчер задач**.
2. Перейдите во вкладку **Автозагрузка** (в Windows 11 она называется "Автозагрузка приложений" и выглядит как иконка спидометра слева).
3. Найдите в списке `AutoTranslator`.
4. Нажмите на него правой кнопкой мыши и выберите **"Отключить"**.

## 🛠 Сборка из исходников (Для разработчиков)

Если вы хотите собрать `.exe` файл самостоятельно или изменить код:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/AutoTranslator.git
   cd AutoTranslator
   ```
2. Установите зависимости:
   ```bash
   pip install keyboard pyperclip deep-translator pystray Pillow pyinstaller
   ```
3. Соберите `.exe` одной командой:
   ```bash
   pyinstaller --noconsole --onefile --name AutoTranslator translator.py
   ```
4. Готовый файл появится в папке `dist`.

## 🛑 Выход из программы
Чтобы закрыть программу, нажмите правой кнопкой мыши на синюю иконку с буквой "T" в трее возле часов и выберите **"Выход"**.
